# Data Dictionary

> **⚠️ Disclaimer — Dummy Data & Learning Purpose**
>
> All data described in this dictionary is **synthetically generated** by `src/data/data_generator.py`
> for learning and testing purposes only. It does not represent any real customers, transactions,
> or business activity.
>
> **If you replace this with real-world data**, the following will likely need to be reviewed and
> adjusted:
> - Column names and data types may differ from your actual source systems
> - The churn definition (transaction silence + web activity + support silence) must be
>   recalibrated against your observed customer behaviour
> - Value ranges, cardinalities, and distributions will be different — update the Pandera schemas
>   in `src/data/data_validator.py` accordingly
> - Feature relevance and importance rankings may shift significantly with real data

## Raw Tables

### `customers` (one row per customer)

| Column | Type | Nullable | Description |
|---|---|---|---|
| customer_id | string | No | Unique customer identifier (CUST0000001 format) |
| registration_date | date | No | Date customer registered on XYZ platform |
| first_purchase_date | date | No | Date of first PC purchase |
| segment | string | No | Customer segment: student / gamer / professional / smb / creative |
| city | string | No | City of residence |
| state | string | No | Indian state |
| city_tier | int | No | 1=metro, 2=major city, 3=smaller city |
| gender | string | No | M / F / Other |
| age_years | int | Yes | Age at registration |
| acquisition_channel | string | No | How customer was acquired |
| product_category | string | No | budget_pc / mid_range_pc / gaming_pc / workstation |
| product_price_inr | float | No | Purchase price in INR |
| warranty_months | int | No | Warranty period (12 or 24 months) |
| amc_active | int | No | Annual Maintenance Contract active: 0/1 |
| **is_churned** | int | No | **Churn event indicator: 1=churned, 0=censored** |
| churn_date | date | Yes | Date churn was determined (null if not churned) |
| observation_end_date | date | No | Last date of observation (churn_date if churned, else 2024-12-31) |
| **duration_days** | int | No | **Survival time in days (key column for all models)** |

### `transactions` (one row per transaction)

| Column | Type | Description |
|---|---|---|
| transaction_id | string | Unique transaction ID |
| customer_id | string | FK → customers.customer_id |
| transaction_date | date | Date of transaction |
| transaction_type | string | initial_purchase / accessory / service_visit / amc_renewal / software / upgrade |
| product_category | string | Associated product category |
| amount_inr | float | Transaction value in INR |
| channel | string | online / store / phone |
| is_returned | int | 1 if item was returned within 30 days |

### `clickstream` (one row per web event)

| Column | Type | Description |
|---|---|---|
| event_id | string | Unique event ID |
| customer_id | string | FK → customers.customer_id |
| event_timestamp | timestamp | Event date and time |
| event_type | string | page_view / product_view / product_comparison / wishlist_add / cart_add / checkout_start / support_chat / spec_download / video_watch |
| session_duration_s | int | Duration of the web session in seconds |
| pages_in_session | int | Pages viewed in the session |
| device_type | string | desktop / mobile / tablet |
| utm_source | string | google / facebook / direct / email / organic / youtube |

### `support_tickets` (one row per ticket)

| Column | Type | Description |
|---|---|---|
| ticket_id | string | Unique ticket ID |
| customer_id | string | FK → customers.customer_id |
| ticket_date | date | Date ticket was raised |
| category | string | hardware_failure / software_issue / warranty_claim / upgrade_query / billing_issue / delivery_issue / general_query |
| resolution_days | int | Days taken to resolve the ticket |
| is_escalated | int | 1 if ticket was escalated to senior support |
| is_resolved | int | 1 if ticket was resolved |
| customer_satisfied | int | 1 if customer marked satisfied post-resolution |
| channel | string | phone / email / chat / walk_in |

## Feature Matrix (model input)

Generated by `src/features/feature_engineering.py` and written to `data/processed/features/`.

### Static Features

| Feature | Category | Description |
|---|---|---|
| tenure_days | Lifecycle | Days from first_purchase_date to as_of_date |
| product_price_inr | Product | Original purchase price |
| warranty_months | Product | Warranty coverage purchased |
| amc_active | Product | AMC currently active |
| warranty_remaining_days | Derived | Days of warranty coverage remaining |
| is_warranty_expired | Derived | 1 if warranty has lapsed |

### RFM Features

| Feature | Category | Description |
|---|---|---|
| total_transactions | RFM-F | Lifetime transaction count |
| total_spend_inr | RFM-M | Lifetime spend in INR |
| days_since_last_transaction | RFM-R | Recency (days) |
| months_since_last_transaction | RFM-R | Recency (months) |
| avg_transaction_value_inr | RFM-M | Mean transaction value |

### Windowed Transaction Features

| Feature | Window |
|---|---|
| tx_count_30d, tx_amount_30d | Trailing 30 days |
| tx_count_60d, tx_amount_60d | Trailing 60 days |
| tx_count_90d, tx_amount_90d | Trailing 90 days |
| tx_count_180d, tx_amount_180d | Trailing 180 days |

### Behavioural Features

| Feature | Description |
|---|---|
| avg_weekly_sessions_30d | Avg sessions/week, trailing 30d |
| avg_weekly_sessions_90d | Avg sessions/week, trailing 90d |
| avg_session_dur_s_90d | Mean session duration (seconds), trailing 90d |
| product_comparison_events_30d | Product comparison events, trailing 30d |
| wishlist_add_events_30d | Wishlist additions, trailing 30d |
| days_since_last_web_visit | Recency of last web session |

### Support Features

| Feature | Description |
|---|---|
| total_support_tickets | Lifetime ticket count |
| support_tickets_30d | Tickets in trailing 30 days |
| support_tickets_90d | Tickets in trailing 90 days |
| avg_resolution_days | Mean resolution time |
| escalation_rate | Fraction of tickets escalated |
| days_since_last_support_contact | Recency of last support interaction |

### Derived / Composite Features

| Feature | Description |
|---|---|
| rfm_recency_score | 1–5 score (5=very recent transaction) |
| rfm_frequency_score | 1–5 score (5=highest frequency) |
| rfm_monetary_score | 1–5 score (5=highest spend) |
| rfm_score | Sum of three RFM scores (3–15) |
| engagement_score | Composite [0,1]: 50% web sessions + 30% satisfaction + 20% recency |

## Score Output Table

Written to `data/processed/scores/score_date=YYYY-MM-DD/`.

| Column | Type | Description |
|---|---|---|
| customer_id | string | Customer identifier |
| score_date | string | Date scores were generated |
| survival_prob_30d | float | P(no churn in next 30 days) |
| survival_prob_60d | float | P(no churn in next 60 days) |
| survival_prob_90d | float | P(no churn in next 90 days) |
| survival_prob_180d | float | P(no churn in next 180 days) |
| median_survival_days | float | Estimated median days to churn |
| churn_risk_segment | string | High / Medium / Low (based on survival_prob_90d) |
| partial_hazard | float | exp(β'x) — relative risk score (higher = more risky) |

### Risk Segment Thresholds

| Segment | Criterion |
|---|---|
| High Risk | survival_prob_90d < 0.30 |
| Medium Risk | 0.30 ≤ survival_prob_90d < 0.60 |
| Low Risk | survival_prob_90d ≥ 0.60 |
